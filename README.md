Try and get 3 of the same icons in a row to win! This is a website built by me showcasing a scratch off ticket like in real life. You can test your luck and see if you win!

How to use: 
-Open the live demo link in any browser. 
-Use your mouse and drag it around the scratch me box
-See if you win!

Features: 
-Audio, from built in web API 
-Animated win events, a blast of confetti will pop up in your screen while highlighting the row
-Win streak counter, to track how many times you won in a row
-Win counter, to track how many times you won in total

How to run it locally: 
-Clone or download this repo 
-Open the project folder 
-Double click index.html to open it directly on your web browser
